遥测

基于 eBPF 的遥测，运行时开销接近于零。用细粒度的 CPU、GPU、调度器、SSD、网络与系统调用度量，把真实存在的问题暴露出来。 network, and syscall metrics to surface real issues.

微秒决定成败的地方 microseconds make or break the product

大多数现成的遥测方案是为 Web 服务设计的——毫秒级延迟和分钟级平均值就够用了。而这个世界的其余部分，需要更好的测量。 web services, where millisecond latencies and minutely averages are acceptable. The rest of the world needs better measurement.

candlestick_chart

高频交易

应用本身已经优化到极致，但你仍然需要确认：环境里没有任何东西会毁掉这一天。Rezolus 用世界上最快的直方图，捕捉最细微的延迟。

directions_car

自动驾驶系统

感知与规划循环有严格的截止时间。Rezolus 在嵌入式系统上运行良好，持续监控可能的争用来源：调度器、GPU、块 I/O、锁，并支持事后回溯。

precision_manufacturing

工业控制与机器人

在实时内核上，排查往往要追到最后一个周期。运行队列延迟、非自愿上下文切换、CPU 迁移、TLB 击落，开箱即有。

database

存储与数据库设备

复杂负载会以难以预料的方式给系统施压。用直方图完整记录负载特征与设备运行行为的动态范围，另有硬盘健康与温度信息可供排查。

cloud_off

离线与边缘环境

本地优先的设计，装进一个静态二进制文件。不需要时序数据库，不向外回传，也不依赖第三方仪表盘。记录直接落在本地磁盘，Viewer 在浏览器里就能打开。

router

网络与运营商基础设施

足够轻量，可以对逼近线速运行的设备提供细粒度的可见性。接口与 ethtool 计数器，加上每 CPU 的调度器与 PMU 行为，让设备在出问题时能开口说话。

为什么可以一直开着

  • 只是一个度量采集代理。 每次刷新的开销可量化、有上界。 and bounded per-refresh cost.
  • 运行在原版的现代内核上。 CO-RE eBPF——不装模块，不打补丁。
  • 本地优先。 Hindsight 常驻缓冲区，按需记录。 record on demand.

六个工具，一个二进制 tools, one binary

从采集到分析的完整可观测性工作流。可以单独使用，也可以接入 OTel。 observability workflow from collection to analysis. Use it alone or integrate with OTel.

monitoring

Agent

通过 eBPF 采集系统度量，开销接近于零。以 HTTP 暴露数据，供下游消费。 eBPF with near-zero overhead. Exposes data over HTTP for downstream consumers.

upload

Exporter

提供 Prometheus 兼容的度量，直方图分位数可配置，开箱即可被抓取。 metrics with configurable histogram percentiles. Scrape-ready.

fiber_smart_record

把高保真的度量快照写入 Parquet 文件，用于基准测试与性能分析。 metric snapshots to Parquet files for benchmarking and performance analysis.

history

Hindsight

在磁盘上维护滚动环形缓冲区。通过信号或 HTTP 触发快照，用于事后分析。 buffer on disk. Trigger snapshots via signal or HTTP for post-incident analysis.

dashboard

Viewer

支持 PromQL 的交互式 Web 仪表盘。浏览已有记录，或从运行中的 agent 实时读取。 with PromQL support. Explore recordings or stream live from a running agent.

AI 引导的分析工具。用 PromQL 查询记录、检测异常、关联度量。 Query recordings with PromQL, detect anomalies, and correlate metrics.

几秒钟就能跑起来 running in seconds

1

安装并启动

#curl -fsSL https://install.rezolus.com | sudo bash

这会添加软件包仓库、安装 Rezolus，并把 agent 作为 systemd 服务启动。支持 Debian、Ubuntu、Rocky Linux 和 Amazon Linux。 Rezolus, and starts the agent as a systemd service. Supports Debian, Ubuntu, Rocky Linux, and Amazon Linux.

info 需要 root 权限，或使用 sudo 运行
2

浏览你的度量

# 打开交互式仪表盘
$rezolus view http://localhost:4241

把 agent 的实时度量接入交互式 Web 仪表盘。agent 监听在 into an interactive web dashboard. The agent listens on 0.0.0.0:4241，因此你也可以让 Viewer 指向远程主机。 you can also point the viewer at a remote host.

需要 Linux 内核 5.8 及以上，以及 root 权限。参见 完整安装文档 installation docs ，了解如何从源码构建或单独管理各项服务。
