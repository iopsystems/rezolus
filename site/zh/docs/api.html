API 参考

各运行模式对外提供的 HTTP 端点。

Agent

默认： 0.0.0.0:4241

GET /

返回 Rezolus 的版本字符串。

GET /metrics/json

当前所有度量值的 JSON 快照，包含计数器、瞬时值与直方图。

GET /metrics/binary

msgpack 编码的二进制快照，由 Exporter、Recorder 与 Hindsight 模式内部使用。

Exporter

默认： 0.0.0.0:4242

GET /metrics

Prometheus 格式的度量。直方图按配置转换为 summary 分位数。

GET /metrics/json

从上游 agent 代理转发的 JSON 度量。

GET /metrics/binary

从上游 agent 代理转发的 msgpack 度量。

Hindsight

可选的 HTTP API，默认： 0.0.0.0:4242

GET /status

缓冲区状态，包含已存数据的时间范围。

GET /dump

以 Parquet 格式下载环形缓冲区的内容。

查询参数

last —— 时间窗口长度，例如 ?last=5m
start —— 起始时间戳，例如 ?start=2024-01-01T12:00:00Z
end —— 结束时间戳
POST /dump/file

把环形缓冲区写入配置指定的磁盘输出文件。

Viewer

本地 Web 服务器

GET /api/v1/query

对内置 TSDB 执行 PromQL 瞬时查询。

GET /api/v1/query_range

对时序数据执行 PromQL 范围查询。

GET /api/v1/labels

所有可用的标签名。

GET /api/v1/label/{name}/values

指定标签的全部取值。

GET /api/v1/metadata

已加载记录的时间范围元数据。
