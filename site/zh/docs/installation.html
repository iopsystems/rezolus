安装

在你的系统上把 Rezolus 跑起来。

#curl -fsSL https://install.rezolus.com | sudo bash

安装脚本会为你的发行版添加软件包仓库、安装 Rezolus，并通过 systemd 启用 agent、exporter 与 hindsight 服务。需以 root 身份或使用 sudo 运行。

info 配置软件包仓库需要完整的 root 权限

支持的发行版

Debian / Ubuntu

Debian 11, 12, 13 · Ubuntu 20.04, 22.04, 24.04

企业级 Linux（Rocky、Alma、RHEL）/ Amazon Linux

Rocky Linux、AlmaLinux、RHEL、CentOS Stream 与 Oracle Linux 9 和 10 · Amazon Linux 2023

服务

软件包会安装三个 systemd 服务：

服务 运行身份 说明
rezolusrootAgent —— 通过 eBPF 采集度量
rezolus-exporterrezolusPrometheus 导出器
rezolus-hindsightrezolus用于事后分析的滚动环形缓冲区
# 查看状态
$sudo systemctl status rezolus
# 修改配置后重启
$sudo systemctl restart rezolus

从源码构建

$git clone https://github.com/iopsystems/rezolus
$cd rezolus
$cargo build --release

安装二进制文件、配置与服务文件：

$sudo cp target/release/rezolus /usr/bin/
$sudo mkdir -p /etc/rezolus
$sudo cp config/*.toml /etc/rezolus/
# 安装 systemd 服务
$sudo cp debian/rezolus.rezolus.service /etc/systemd/system/rezolus.service
$sudo cp debian/rezolus.rezolus-exporter.service /etc/systemd/system/rezolus-exporter.service
$sudo cp debian/rezolus.rezolus-hindsight.service /etc/systemd/system/rezolus-hindsight.service
$sudo systemctl daemon-reload
$sudo systemctl enable --now rezolus

环境要求

  • • eBPF 功能需要 Linux 内核 5.8 及以上
  • • root 权限（agent 需以 root 运行才能使用 eBPF）
  • • 架构：x86_64 与 ARM64
  • • Rust 工具链（仅在从源码构建时需要）

注意： macOS 上支持 CPU 与 Apple Silicon GPU 度量。基于 eBPF 的采样器（调度器、块 I/O、TCP、系统调用）需要 Linux。

安装

$brew install iopsystems/iop/rezolus

formula 位于 iopsystems/homebrew-iop tap 中； brew 会在首次安装时自动添加它。

安装脚本做的是同一件事；当系统上没有 Homebrew 时，它会回退到用 Cargo 构建：

$curl -fsSL https://install.rezolus.com | bash

运行

在 macOS 上，agent 需要手动运行（没有 systemd）：

$sudo rezolus /etc/rezolus/agent.toml
# 验证
$curl http://localhost:4241/metrics/json | jq .
