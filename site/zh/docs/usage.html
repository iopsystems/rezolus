使用

长期运行

持续部署，在系统的整个生命周期内观测它。

运行 agent，并用 Prometheus 抓取

标准的常开式监控。agent 通过 eBPF 采集，并把数据提供给 exporter，由它以 Prometheus 格式提供在 :4242.

# 通过 systemd 安装：两个服务都已启用
$sudo systemctl start rezolus rezolus-exporter
# 让 Prometheus 指向 :4242，并把 Grafana 接到该数据源

用 Hindsight 维护滚动缓冲区

适用于无法预测何时会出问题的系统。Hindsight 在磁盘上维护高分辨率快照的滚动环形缓冲区；故障发生时触发一次快照，就能在 Viewer 中加载事发前后的时间窗口。

$sudo systemctl start rezolus-hindsight
# 按需触发快照（信号或 HTTP）
$sudo pkill -HUP -f rezolus-hindsight
# 或通过 HTTP API 触发，便于脚本调用
$curl -X POST http://localhost:4243/snapshot

合并你自己的度量

把应用自身 OpenTelemetry/Prometheus 端点的度量，拉进与 rezolus 系统度量同一份记录里。便于把服务级 KPI（请求速率、p99 延迟）与内核级事件关联起来。

rezolus-record.toml
[recording]
interval = "1s"
output = "combined.parquet"
[[endpoints]] # rezolus agent
url = "http://127.0.0.1:4241"
source = "rezolus"
[[endpoints]] # 你自己服务的 /metrics
url = "http://127.0.0.1:9090/metrics"
source = "my-service"
role = "service"
protocol = "prometheus"
$rezolus record --config rezolus-record.toml

一次性

针对某次具体排查的临时采集与实时连接。

采集一份用于性能分析的记录

在跑负载的同时以足够高的分辨率记录，才能抓到你要找的东西。产出的 parquet 是自包含的——之后可以随时打开、分享、归档。

# 以 100ms 间隔，对运行中的 agent 记录 60 秒
$rezolus record -i 100ms -d 60s -o run-1.rez
# 在 Viewer 中打开
$rezolus view run-1.rez

A/B 对比

并排比较两份记录——变更前后、基线与实验组，或者两台不同的机器。Viewer 会把每张图渲染两次，并把差异呈现出来。

$rezolus view baseline.parquet experiment.parquet
# 用别名让界面上的标签更清晰
$rezolus view before=run-a.parquet after=run-b.parquet

实时跟看远程 agent

跳过记录步骤，直接把 agent 的数据流式送进浏览器仪表盘。适合对远程主机做快速检查，又不想在磁盘上留下任何东西。

$rezolus view http://agent-host:4241

离线分析

数据采集完成之后要做的事——在 Viewer 里，或者通过 MCP 服务器。

A/B 对比

与一次性场景中的流程相同：任意两份记录都可以比较，无论它们何时采集、如何采集。当你已经积累了一批运行记录，想在特定两次之间找出回归时尤其有用。

$rezolus view 2025-12-01.parquet 2026-01-15.parquet

按 cgroup / 容器下钻

CPU、调度器与系统调用采样器会输出按 cgroup 划分的度量。在 Viewer 中把 cgroup 选择器切到某个容器，就只看它的 CPU 使用率、运行队列延迟与系统调用构成——把单个租户从嘈杂的主机上隔离出来。

$rezolus view recording.parquet
# 在 Viewer 中：Cgroups 区域 → 选择一个容器 → 所有图表随之切换范围

用 MCP 做 AI 辅助分析

把 MCP 服务器指向一份记录，让 LLM 驱动的客户端去调查。内置工具涵盖异常检测（MAD / CUSUM / FFT）、度量相关性分析，以及针对该记录的任意 PromQL 查询。

# 一次性 CLI 模式
$rezolus mcp detect-anomalies recording.parquet
# 或作为 stdio 服务器运行，供 Claude Desktop / Cursor 使用
$rezolus mcp
